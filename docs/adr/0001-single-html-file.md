# ADR 0001: קובץ HTML אחד

**סטטוס:** מאושר · 2026-11-02

## הקשר
הכלי מופץ בסדנאות: קישור, QR, לפעמים קובץ במייל או בוואטסאפ. המנחה צריך שזה יעבוד גם כשהרשת באולם חלשה, וגם כשמישהו פותח את הקובץ מהמחשב.

## החלטה
המוצר הוא `index.html` יחיד, שעובד כפי שהוא, בלי שלב build. הקובץ במאגר הוא בדיוק הקובץ שנשלח.

## חלופות שנשקלו
- **Vite + TypeScript, עם build לקובץ אחד.** מודולים אמיתיים וטיפוסים. אבל אז יש פער בין מה שנכתב למה שנשלח, ותלות בשרשרת כלים. בגודל הזה, המחיר גבוה מהתועלת.
- **אתר רב-קבצי.** לא נפתח כקובץ מקומי, ושובר שליחה במייל.

## השלכות
- מודולריות נשמרת בבלוקים ובבדיקות, לא במערכת הקבצים (ADR 0003).
- אין TypeScript. `"use strict"` ו-JSDoc כשצריך.
- בדיקת ארכיטקטורה נכשלת על כל הפניה לקובץ מקומי.
