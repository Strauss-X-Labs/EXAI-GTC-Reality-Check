# ADR 0002: התוכן כ-Spec בבלוק JSON

**סטטוס:** מאושר · 2026-11-02

## הקשר
התוכן (פרדיגמות, היגדים, סעיפי ספר החוקים) משתנה יותר מהקוד, ומי שמשנה אותו הוא יועץ, לא מפתח. בגרסה המקורית התוכן היה מפוזר בשלושה מערכי JS, ושורת תוכן אחת ("כדי לצמוח") הייתה מקודדת בתוך הלוגיקה.

## החלטה
כל התוכן יושב ב-`<script type="application/json" id="content">`. הקוד קורא אותו ב-`JSON.parse`. פרק בספר החוקים הוא חלק מהפרדיגמה שלו (`paradigm.chapter`), לא מערך מקביל. הדגשה בסעיף מוגדרת בנתונים (`hot`, `highlight`).

## חלופות שנשקלו
- **מערכי JS.** קל לשבור תחביר בעריכה ידנית, ואין גבול ברור בין נתונים לקוד.
- **קובץ JSON חיצוני.** שובר את ADR 0001.

## השלכות
- עריכת תוכן = עריכת JSON בלבד. סכמה ואינווריאנטים נבדקים ב-CI.
- שני מערכים מקבילים שיכלו לצאת מסנכרון הפכו למבנה אחד.
- טקסטים של ממשק (כפתורים, הוראות) נשארים ב-markup. רק תוכן אבחוני עובר ל-Spec.
