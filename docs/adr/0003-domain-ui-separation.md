# ADR 0003: הפרדת Domain ו-UI בתוך הקובץ

**סטטוס:** מאושר · 2026-11-02

## הקשר
בגרסה המקורית חישוב הציון, בחירת הפרדיגמה החלשה וציור ה-SVG היו באותן פונקציות. אי אפשר היה לבדוק "מה הציון" בלי דפדפן.

## החלטה
Ports & Adapters בקטן:
- `#rc-domain`: פונקציות טהורות, חשופות כ-`globalThis.RCDomain`, מוקפאות.
- `#rc-ui`: ה-Adapter היחיד לדפדפן. לא מחשב ציונים בעצמו.

תלות חד-כיוונית: Content → Domain → UI.

## השלכות
- בדיקות Domain רצות ב-Node עם `vm`, על הטקסט שמחולץ מ-`index.html`.
- בדיקת ארכיטקטורה אוסרת גישה לדפדפן, לזמן ולאקראיות בתוך ה-Domain.
- מספרים שהיו קשיחים (18, 6.5/18, 3) נגזרים עכשיו מה-Spec.
