# הפעלת "איך אני למול הכלל"

פעם אחת, בערך 5 דקות. צריך גישת עריכה לגיליון.

## 1. להדביק את הקוד
1. לפתוח את הגיליון ← **Extensions ← Apps Script**
2. למחוק את מה שיש ב-`Code.gs` ולהדביק את התוכן של [`Code.gs`](Code.gs)
3. לשמור (Ctrl+S)
4. בתפריט הפונקציות לבחור `setup` ← **Run**. בפעם הראשונה Google יבקש הרשאה, לאשר. נוצרת לשונית `responses` עם כותרות.

## 2. לפרסם כ-Web App
1. **Deploy ← New deployment ← Web app**
2. **Execute as:** Me
3. **Who has access:** Anyone (בלי זה דפדפן של משתתף לא יוכל לשלוח)
4. **Deploy** ← להעתיק את ה-URL שנגמר ב-`/exec`

## 3. להכניס את הכתובת לדף
ב-`index.html`, בבלוק `#config`:

```json
{
  "endpoint": "https://script.google.com/macros/s/XXXX/exec",
  "minCompare": 5
}
```

`npm test` מוודא שהכתובת בפורמט הנכון. push ל-main מעלה ל-Pages.

## לבדוק שעובד
- לפתוח את ה-URL בדפדפן. צריך לחזור `{"ok":true,"service":"reality-check"}`.
- למלא את השאלון וללחוץ על הכפתור. צריכה להופיע שורה ב-`responses`.

## שימו לב
- **שיתוף הגיליון:** אפשר להשאיר אותו פרטי לגמרי. ה-Script רץ בשמכם ולא צריך שיתוף. אם הגיליון פתוח ב"כל מי שיש לו קישור", כל מי שיקבל את הקישור יוכל לראות את כל התשובות.
- **עדכון קוד:** אחרי שינוי ב-Code.gs: Deploy ← Manage deployments ← עריכה ← Version: New. ככה ה-URL נשאר אותו URL.
- **איפוס לפני הסדנה:** למחוק את השורות מתחת לכותרת בלשונית `responses`.
- **שינוי היגדים:** להעלות את `meta.version` ב-`#content`. הממוצע מחושב רק לאותה גרסה.
